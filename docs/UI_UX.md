# UI_UX.md — Дизайн-система и UX-принципы

## 1. Философия дизайна

- **Простота** — минимум когнитивной нагрузки, один основной сценарий на экран.
- **Воздух** — щедрые отступы, отсутствие визуального шума.
- **Забота и спокойствие** — мягкая цветовая палитра, округлые формы, отсутствие агрессивных красных/тревожных акцентов вне явных предупреждений.
- **Крупные элементы** — читаемая типографика, крупные touch-таргеты (≥44px).
- **Плавность** — все переходы и появления анимированы через Framer Motion (150–300ms, easing `ease-out`).

## 2. Mobile First

Проектирование всегда начинается с брейкпоинта 360–414px (типичный смартфон), затем расширяется:

| Брейкпоинт | Диапазон | Layout |
|---|---|---|
| `base` | 0–639px | 1 колонка, bottom navigation, полноэкранные карточки |
| `sm` | ≥640px | Увеличенные отступы, до 2 колонок в сетках |
| `md` | ≥768px | Планшет: 2–3 колонки, боковая навигация опционально |
| `lg` | ≥1024px | Десктоп: боковой sidebar вместо bottom nav, до 3–4 колонок |
| `xl` | ≥1280px | Максимальная ширина контента 1280px, центрирование |

Bottom Navigation — основной паттерн навигации на мобильных (base/sm). На `lg+` дублируется как верхнее/боковое меню, bottom nav скрывается.

## 3. Дизайн-токены

Определены как CSS-переменные (совместимо с shadcn/ui theming) в `app/globals.css`, используются через Tailwind.

### Цвета (light theme, HSL)

| Токен | Назначение |
|---|---|
| `--background` | Основной фон (тёплый почти белый) |
| `--foreground` | Основной текст |
| `--primary` | Тёплый бирюзово-синий (спокойствие, доверие) |
| `--secondary` | Мягкий персиковый/жёлтый акцент (тепло, забота) |
| `--muted` | Фон второстепенных блоков |
| `--accent` | Акцентные состояния (hover, выделение) |
| `--destructive` | Только для реальных предупреждений/ошибок |
| `--success` | Подтверждения, выполненные чек-листы |
| `--border` / `--ring` | Границы и фокус-кольца |

Dark theme — те же токены, инвертированные по яркости, с сохранением тёплого, некорпоративного характера (не чистый чёрно-белый).

### Типографика

- Шрифт: системный/geist-подобный sans-serif с хорошей поддержкой кириллицы и казахской латиницы/кириллицы.
- Шкала: `text-sm` (14px) — вспомогательный текст, `text-base` (16px) — основной, `text-lg`–`text-3xl` — заголовки экранов и секций.
- Жирность: заголовки `font-semibold`/`font-bold`, тело — `font-normal`.

### Радиусы и тени

- Базовый радиус — крупный: `--radius: 1rem` (16px) для карточек, `9999px` для пилюль/бейджей/кнопок-иконок.
- Тени мягкие, рассеянные (`shadow-sm`/`shadow-md`), без резких контрастных теней.

### Иконки

- `lucide-react` (поставляется с shadcn/ui) — единый набор иконок, line-style, скруглённые концы.

## 4. Компонентная база

shadcn/ui как основа (Button, Card, Input, Dialog, Sheet, Tabs, Badge, Avatar, Progress, Skeleton, Toast/Sonner и т.д.), кастомизированные под токены проекта. Композитные паттерны:

- **BottomNavigation** — 5 основных пунктов (Главная, Знания, Нормы/Чек-листы через Sheet, Игры, Профиль) либо адаптивный набор до 5 иконок с активным состоянием.
- **ContentCard** — универсальная карточка для статьи/игры/чек-листа с обложкой, заголовком, метатегами.
- **SectionHeader** — заголовок секции + опциональная ссылка «Смотреть все».
- **EmptyState** — дружелюбные иллюстрации/иконки + текст для пустых состояний.
- **DisclaimerBanner** — переиспользуемый компонент медицинского дисклеймера (используется в AI Chat, статьях здоровья).

## 5. Анимации (Framer Motion)

- Появление списков — стаггер (staggered fade+slide-up), 20–40ms между элементами.
- Переходы между табами/страницами — fade+slight slide, без резких скачков layout.
- Микровзаимодействия: нажатие кнопки — `scale: 0.97`, чекбоксы чек-листа — анимация подтверждения (галочка + лёгкий bounce).
- Уважение к `prefers-reduced-motion` — анимации отключаются/упрощаются.

## 6. Тон UX-копирайта

См. также [I18N.md](I18N.md) и [SAFETY.md](SAFETY.md).

- Обращение на «вы», тёплое, но не инфантильное.
- Никогда не использовать паникующие формулировки («Внимание! Опасность!») вне реальных предупреждений о безопасности.
- Пустые состояния и ошибки — с юмором и заботой, без технического жаргона («Что-то пошло не так» вместо кода ошибки).

## 7. Тёмная тема

Полная поддержка dark mode через `next-themes` + `class` стратегию Tailwind, переключатель в Настройках (light/dark/system).

## 8. Доступность

- Контраст текста ≥ 4.5:1 (WCAG AA).
- Все интерактивные элементы фокусируемы с клавиатуры, видимый `focus-visible` ring.
- Alt-тексты для изображений, ARIA-labels для иконок-кнопок.

## 9. V1 — паттерны ежедневной ленты

- **Today screen** — вертикальная лента секций (`SectionHeader` + контент), а не сетка ссылок: приветствие → «Сегодня рекомендуем» → «Быстрые действия» → «Продолжить» → «5 минут вместе» → «А вы знали?» → «Спокойный момент» → статьи недели → эмоциональная поддержка.
- **Быстрые действия** — горизонтальные pill-кнопки (`h-11`, скролл на мобильном), ведущие либо в AI-чат с предзаполненным вопросом, либо в конкретный раздел.
- **Карточки фактов и спокойных моментов** — тот же язык карточек, что и статьи/чек-листы (иллюстрация сверху, бейдж категории, `shadow-soft`/`shadow-card`), чтобы не создавать визуально отдельную подсистему.
- **Иллюстрации V1** — добавлены `MusicNoteIllustration`, `BookReadingIllustration`, `ChecklistIllustration`, `AiAssistantIllustration` в `shared/illustrations/`, той же двухцветной плоской системой (`tone` + `toneVars`), что и в Этапе 1.
- **Меню «Ещё»** — bottom sheet для вторичных разделов (Нормы, Чек-листы, Спокойствие, Настройки), когда bottom navigation ограничена пятью основными пунктами.

## 10. Библиотека статичных placeholder-изображений

`public/images/placeholders/` — набор крупных (800×450) SVG-сцен в фирменном стиле, для мест, где в будущем появятся индивидуальные обложки (маркетинговые страницы, превью для шеринга, крупные баннеры), но пока не оправдан отдельный React-компонент иллюстрации:

- `speech-development.svg` — речь и развитие
- `reading.svg` — чтение
- `play.svg` — игра
- `sleep.svg` — сон
- `communication.svg` — общение
- `family.svg` — семья

Это статичные файлы (не React-компоненты), поэтому цвета в них захардкожены в фирменные HEX-значения из `docs/BRAND.md` §2, а не в CSS-переменные — внешний `<img src>` не имеет доступа к CSS custom properties страницы. Для тем, которые уже используются как маленькие карточные иллюстрации, продолжайте использовать компоненты `shared/illustrations/*`, а не эти файлы.
