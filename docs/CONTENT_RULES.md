# CONTENT_RULES.md — Правила формулировок

Этот документ дополняет [SAFETY.md](SAFETY.md) конкретными правилами для редакторов и AI-контента, введёнными вместе с V1 (факты, спокойные моменты, быстрые вопросы AI). Правило одно на весь проект:

**Приложение не диагностирует, не лечит и не заменяет специалиста.** Это особенно важно там, где велик соблазн дать громкое обещание: факты о развитии, описания музыки/звуков, ответы AI-помощника.

## 1. Запрещённые формулировки

Это правило действует с нулевой терпимостью к исключениям — ни «в порядке
исключения для этого факта», ни «но здесь же явно полезно» не оправдывают
нарушение. Никогда не пишем и не позволяем AI писать:

- «музыка развивает интеллект» / «музыка улучшает мозг»
- «музыка лечит» / «звук лечит»
- «это признак аутизма» (или любого другого диагноза)
- «у ребёнка диагноз ...»
- «обязательно поможет» / «гарантированно решит проблему»
- любые формулировки, категорично утверждающие норму или патологию на основе введённых пользователем данных
- названия конкретных лекарств, БАДов, ноотропов, дозировок — в любом контексте, включая ответ на прямой вопрос родителя о конкретном препарате (см. [AI.md](AI.md) §3, [AI_COMPANION.md](AI_COMPANION.md) §5)
- «единственно правильный способ» / «так делают все хорошие родители» — обесценивающие альтернативные, тоже нормальные родительские практики
- любая формулировка, которая может быть прочитана как реклама конкретного B2B-партнёра (специалиста, центра) внутри контента для родителя — коммерческие договорённости из [PRODUCT.md](PRODUCT.md) §11 никогда не влияют на текст фактов/советов/статей

## 2. Разрешённые, безопасные формулировки

Вместо категоричных обещаний используем осторожные, поддерживающие конструкции:

- «может помочь создать спокойную атмосферу»
- «может стать частью вечернего ритуала»
- «подходит для спокойного совместного времени»
- «может быть полезно попробовать»
- «стоит обсудить со специалистом»
- «наблюдайте без давления»
- «главное — спокойное общение»

## 3. Где это особенно важно

| Раздел | Риск | Как избегаем |
|---|---|---|
| Факты («А вы знали?») | Излишне уверенные обобщения о развитии | Факты формулируются как общие закономерности («часто», «обычно»), без привязки к конкретному ребёнку читателя |
| Советы дня («Полезно сегодня», `entities/tip`) | Совет читается как категоричное предписание («нужно делать именно так», иначе будет плохо) | Только рекомендательные формулировки («стоит попробовать», «может помочь»); ни один совет не формулируется как единственно верный способ воспитания |
| Спокойные моменты (`/calm`) | Обещание терапевтического эффекта музыки/звука | Только «может помочь», «может стать частью ритуала» — никогда «лечит» или «развивает интеллект» |
| 5 минут вместе (`/games/daily`) | Давление на родителя «делать правильно» | Каждая игра сопровождается напоминанием «Главное — не заставлять, а играть вместе» |
| AI-чат | Ложное чувство диагностики через чат | Системные ответы избегают слова «диагноз», направляют к специалисту при описании стойких/тревожных симптомов, эмоционально поддерживают до того, как дать факт (см. [AI.md](AI.md)) |
| Быстрые действия на Главной | Тревожные формулировки вопросов («что не так с ребёнком») | Вопросы сформулированы нейтрально («Ребёнок не реагирует на имя, что делать?»), без ярлыков и паники |

## 4. Проверочный чек-лист перед публикацией нового контента

- [ ] Нет слов «диагноз», «лечит», «гарантированно», «обязательно поможет».
- [ ] Есть смягчающая формулировка («может», «часто», «стоит обсудить») там, где утверждение не абсолютно.
- [ ] Тон спокойный, поддерживающий, без паники и без ярлыков.
- [ ] Если тема касается тревожных/острых симптомов — есть явная отсылка к специалисту или экстренной помощи.
- [ ] Текст присутствует на русском и казахском языках с одинаковым уровнем осторожности формулировок (перевод не «усиливает» и не «смягчает» смысл).
