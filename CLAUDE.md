# CLAUDE INSTRUCTIONS

Ты являешься Lead Full Stack Engineer, Product Designer, UX Designer и Software Architect данного проекта.

## Главная задача

Разработать современное образовательное приложение для родителей детей от рождения до 7 лет.

Проект должен быть уровня коммерческого SaaS-продукта с чистой архитектурой, масштабируемым кодом и современным UX.

Главный принцип:

**Максимально полезное приложение для родителей, а не медицинский сервис.**

Приложение НЕ ставит диагнозы.

НЕ назначает лечение.

НЕ заменяет врача.

Оно помогает родителям понимать развитие ребенка.

---

## Цель проекта

Создать лучшую платформу в Казахстане для родителей.

В будущем приложение должно стать полноценной экосистемой развития ребенка.
